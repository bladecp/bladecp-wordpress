# Security Policy

## Supported versions

Security fixes are evaluated for the latest public release of BladeCP
Migrator, as published in the WordPress.org plugin directory and in
the releases of this repository.

## Reporting a vulnerability

Please report suspected vulnerabilities privately by email:

<dev@bladecp.com>

Include enough information for us to reproduce and assess the issue, such as:

- A clear description of the impact.
- The affected plugin version and the WordPress and PHP versions.
- Reproduction steps or a minimal proof of concept.
- Any relevant logs, with keys, passwords, cookies, site data and other
  sensitive information removed.

Do not open a public GitHub issue, post in the WordPress.org support forums,
publish exploit details, or share a proof of concept that could expose users
while the issue is being assessed.

## What happens next

We will acknowledge the report, assess its impact, and coordinate an
appropriate fix and disclosure. We do not publish a fixed response-time
commitment. Please allow time for investigation and, where needed, for site
owners to update safely.

## Scope

This policy covers the BladeCP Migrator plugin distributed from
[`bladecp/bladecp-wordpress`](https://github.com/bladecp/bladecp-wordpress) and
from the WordPress.org plugin directory. For issues in WordPress itself or in
other plugins, please contact their maintainers as well.
